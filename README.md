# 🌐 NetTrace - Network Mapping & Patch Management Platform

منصة محلية (Localhost / Self-Hosted) خفيفة وعالية الكفاءة لإدارة وتوثيق البنية التحتية لشبكات الاتصال، نقط الحائط (Data Drops)، الباتش بانل (Patch Panels)، وسويتشات الشبكة والـ VLANs مع إمكانية التتبع البصري الكامل (End-to-End Tracing) والتكامل مع ملفات الإكسيل.

---

## 🚀 طريقة التشغيل المباشر (Quick Start)

### الطريقة الأولى: بنقرة واحدة (Windows)
فقط قم بتشغيل الملف:
```cmd
start_platform.bat
```
سيقوم ببدء السيرفر وفتح المنصة تلقائياً على المتصفح عبر الرابط: `http://localhost:5000`

### الطريقة الثانية: عبر سطر الأوامر (Terminal / Linux Server)
```bash
# تشغيل السيرفر مباشرة
node backend/src/server.js
```

## 🌟 الميزات الرئيسية (Core Features)

1. **البحث والفلترة الفورية (Instant Smart Search):**
   * بحث شامل بأي حقل (رقم النقطة `Drop_ID`، الغرفة، الموظف، السويتش، البورت، الـ IP، أو الـ VLAN).
   * فلاتر متعددة للأدوار، الراكات، السويتشات، وحالة النقطة.

2. **كارت التتبع البصري الكامل (End-to-End Visual Trace):**
   * عرض مسار النقطة بالكامل بنقرة زر واحدة:
     $$\text{Wall Outlet} \longrightarrow \text{Patch Panel (Port)} \longrightarrow \text{Patch Cord} \longrightarrow \text{Switch (Port \& VLAN)} \longrightarrow \text{Device}$$
   * إمكانية نسخ ملخص المسار بنقرة واحدة لتسهيل التواصل مع فرق الصيانة.

3. **مصفوفة البورتات المرئية (Interactive Port Matrix):**
   * محاكاة بصرية لمصفوفة بورتات الـ Patch Panels والسويتشات (24 و 48 بورت).
   * إضاءات حالة البورت بألوان معتمدة:
     * 🟢 **Active** (شغال ومربوط)
     * ⚪ **Free** (متاح وغير مربوط)
     * 🟡 **Reserved** (محجوز)
     * 🔴 **Damaged** (تالف / عطل)
   * الضغط على أي بورت يفتح كارت التتبع الفوري.

4. **إدارة وتزامن الإكسيل (Excel Sync & Manager):**
   * زر لتحميل **قالب الإكسيل المعتمد** الجاهز.
   * أداة سحب وإفلات لرفع شيت الإكسيل والتحديث التلقائي حسب الـ `Drop_ID`.
   * تصدير جميع بيانات الشبكة الحالية إلى ملف Excel منسق بضغطة زر.

5. **لوحة تحليلات السعة والـ VLAN (Analytics & Capacity):**
   * نسبة إشغال بورتات السويتشات (Port Utilization).
   * توزيع الـ VLANs والأجهزة المتصلة (PC, IP Phone, Access Points, CCTV, Printers).

## 📊 التنسيق المعتمد لشيت الإكسيل (16 عمود)

| اسم العمود (English) | اسم العمود (بالعربي) | الوصف | إجباري؟ |
| :--- | :--- | :--- | :--- |
| `Drop_ID` | رقم النقطة | المعرف المكتوب على الحائط (مثل: `FL01-R101-D1`) | **نعم** |
| `Building` | المبنى | اسم أو رقم المبنى | لا |
| `Floor` | الدور | الدور الموجود به النقطة (مثل: `Floor 1`) | **نعم** |
| `Room_Office` | الغرفة / المكتب | رقم أو اسم الغرفة | **نعم** |
| `User_Device` | المستخدم / الجهاز | اسم الموظف أو الجهاز المتصل | لا |
| `Rack_Name` | اسم الراك | اسم الراك الموجود به الباتش بانل (مثل: `Rack-01`) | **نعم** |
| `Patch_Panel` | الباتش بانل | رمز الباتش بانل (مثل: `PP-A`) | **نعم** |
| `Patch_Port` | بورت الباتش بانل | رقم البورت (1 إلى 48) | **نعم** |
| `Switch_Name` | اسم السويتش | اسم السويتش المربوط به (مثل: `SW-Core-01`) | **نعم** |
| `Switch_IP` | آي بي السويتش | الـ IP الخاص بالسويتش | لا |
| `Switch_Port` | بورت السويتش | منفذ السويتش (مثل: `Gi1/0/1`) | **نعم** |
| `VLAN_ID` | رقم الفيلان | رقم الـ VLAN المفعلة على البورت | لا |
| `VLAN_Name` | اسم الفيلان | وصف الـ VLAN (مثل: `Data_Users`) | لا |
| `Status` | حالة النقطة | `Active`, `Free`, `Reserved`, `Damaged` | **نعم** |
| `Device_Type` | نوع الجهاز | `PC`, `IP Phone`, `Printer`, `Access Point`, `CCTV` | لا |
| `Notes` | ملاحظات | أي ملاحظات أو تفاصيل كابل التوصيل | لا |
